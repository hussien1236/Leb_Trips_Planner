# LebTrips

## Features
- Interactive web app for planning trips in Lebanon.
- Built with JavaScript, React.js, Vite, and styled using Tailwind CSS.
- Data management through Firebase Firestore for real-time updates.
- Trip recommendations powered by Gemini AI API.
- Secure Google authentication for user login.
- Integration with Google Maps for detailed location information.

## Usage
LebTrips helps travelers discover and plan personalized trips across Lebanon. Users can:
- Sign in securely using their Google accounts.
- Explore curated trip recommendations generated by AI based on user preferences.
- View detailed maps and location information via Google Maps links.
- Save and manage favorite trips using real-time data stored in Firebase Firestore.
